# Immutable geographic migration evidence

These are pre-change and pre-batch backups, not active monitoring data. Never
import this directory into runtime, source discovery, schedules or exports.
The original manifest records SHA-256 hashes and the base commit. Batch manifests
support safe replay/rollback. Regional semantics and results are documented in
`docs/GEOGRAPHIC_COVERAGE_MIGRATION.md`. Existing public historical news and older
legacy audit documents were not rewritten as if they had always tracked 50.
