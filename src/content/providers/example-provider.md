This file is a frontmatter template for future DAJC integration ecosystem
providers. It is never shown on the site because `status: draft`. Copy it,
rename the file, and fill in real details only once a real relationship
exists.

Before setting `status: active`, confirm:
- the provider's name is cleared for public use,
- `logoApproved: true` only once a logo file has been approved for use and
  added under `public/assets/providers/`,
- `descriptionApproved: true` only once `shortDescription` and
  `collaborationArea` have been written and approved,
- `relationshipStatus` and `integrationStatus` reflect the real, current
  state - never `formal_partnership` or `available` unless that is
  genuinely and publicly true.
