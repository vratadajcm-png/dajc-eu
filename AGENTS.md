One traceable code slice at a time, with source evidence, tests (including negative safety/privacy/path traversal cases), user isolation and PR. Read/write only the paths granted by the active workflow. This file does NOT grant broader permissions. Existing production env, keys, paid third-party APIs, source licences, legal text, provider contracts and deployment remain under separate approval.

**Owner decisions:** if a blocking requirement is ambiguous, create `[DAJC AI][OWNER DECISION]` issue if GitHub issue write permitted; otherwise place `OWNER_DECISION_REQUIRED` in PR or job report with one exact question, proposed safe option, A/B alternatives, source link, cost/privacy/security impact and what work may continue. Do not secretly choose legal/privacy/payment/retention defaults.

**External source hygiene:** old mail or public web link does not confer a license/permission or give Claude authorization to read connected apps. Use in-repo sanitized source registry and request owner extraction if a private contract is required. Don't copy credentials or private correspondence into this public repo.

`docs/` files are **implementation maps** subordinate to the current owner-reviewed canonical master. Distinguish design, implemented, passing unit tests, approved sandbox and deployed/live.
